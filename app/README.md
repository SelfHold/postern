# Postern app

The Flutter UI of Postern. It only draws: SSH, SFTP, transfers and sync live in the Go
core (`../core`), reached over gRPC (`../proto/postern.proto`).

Build and run it through the repository's `Makefile` (`make app-run`, `make build-linux`,
`make app-test`); see the [README](../README.md) and [CONTRIBUTING.md](../CONTRIBUTING.md).
